# 자동 반복 호출기 폐기 (2026-11-04)

사용자 지시: "기존 자동 반복 호출기 기능 삭제하고 이력만 보관해."

- 삭제한 실행 코드: 토론진행기.py(연속 토론 진행기), 자동재개감시.py(사용량 한도 뒤 자동 재시작), 현황문서.py(진행기 현황 문서), test_debate_broker.py, test_trade_broker.py.

- 이력: 토론 기록(이 폴더의 토론.md·토론규칙.md 등)과 docs/ai-history는 그대로 둔다. 삭제한 코드는 git 이력에 남아 있다. 마지막 판은 커밋 432512e에서 볼 수 있다: `git show 432512e:debate_tools/토론진행기.py`
- 회사 PC 바탕화면 AI토론장의 같은 계열 스크립트 9개와 'AI토론 시작' 바로가기는 실행되지 않도록 .txt로 바꿔 AI토론장/보관_자동호출기_폐기_20261104/에 보관했다.
- 집 PC에도 같은 진행기·감시기가 실행 중이면 종료하고, 바탕화면 토론장 폴더의 진행기 스크립트를 같은 방식으로 보관한다.
