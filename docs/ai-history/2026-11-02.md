# 2026-11-02 작업 기록 (집 PC, Claude Code 주도)

모든 시각은 KST. 이 기록은 Claude Code 세션이 작성했다. 같은 날 같은 PC의 Codex 세션 기록은 `codex-session/`에 있다.

## 배경
- 사용자는 낮(회사)에 만든 작업을 집에서 이어가려 했다. 처음에는 `leehw4321/coin`(V3 계열)에서 작업했으나, 실제 본 프로젝트는 `leehw4321/ai-trade`(V4 + V5 + 토론 도구)임을 사용자 스크린샷으로 확인했다(13:05 커밋 ff3c263).
- 회사에서 두 AI가 바탕화면 문서로 주고받던 토론 원문은 이 PC에 없다. `ai-trade` 인계 문서에 따르면 개인정보 때문에 원문 전문을 일부러 GitHub에서 제외했다. 그래서 과거 발언은 복원되지 않았다(재구성 문서는 `coin` 저장소 `토론기록/00_합의_복원본.md`에 있고 원문이 아니다).

## 작업 순서
1. `coin` 저장소 최신 코드 확인(a2dbb30), 테스트 297개 통과. 바탕화면 "코인봇 V3 실행" 바로가기 생성.
2. `coin`에 청산 기록 보강(버전·수수료·보유 시간 등)과 호가 5초 단절·복구 이벤트 기록을 추가, 테스트 299개 통과, 커밋 b363497 푸시. 토론기록 폴더 521d0f1까지 푸시. *(본류 프로젝트가 아니므로 V5와 무관)*
3. `ai-trade`를 받아 V5 테스트 47개 통과 확인. 토론 진행기 `--continuous-run` 시작(20:37).
4. 진행기 중단 원인 수정: `토론.md` 템플릿에 안건 표 끝 표시 `상태: 제안` 줄이 없어 새 안건을 못 넣었다. 줄 추가 후 재시작. 20:52에 진행기가 로그 없이 종료돼(원인 불명) 21:06 재시작.
5. 사용자 안건 추가: 급등 꼭지 부근 매수 후 급락 패턴(운용목표.md). 10/25 구버전 단타봇 거래 35건 집계를 근거로 제공(공유_근거자료.md 근거 1): 진입 후 +3% 미도달 26건 중 승 2건, 도달 9건 중 승 8건. 단 최고%는 결과를 본 뒤의 값이라 필터가 아니다.
6. 사용자 제공 BIRB 1분봉 차트를 근거 2로 추가. Claude의 초기 해석("거래량 폭발 이후 매수")은 평균가만으로는 매수 시점을 알 수 없다는 지적으로 **철회**했다(토론 안건 10 합의).
7. V5 청산 규칙 확인: 익절 규칙 없음, 순환 매도 + 고정 ATR 손절. 사용자의 메타플렉스 질문에 답함(보유 여부는 이 PC에서 확인 불가).
8. 실거래 이어받기 요청에 대해 **실거래를 켜지 않았다.** 이유: 회사 봇이 실행 중일 수 있음, `data/live/live.json` 없음, 이 PC의 `v5/.env` 없음, 코드에 '보유종목 포함 전체 위임'이 없음.
9. 토론 규칙 개정(21:00, `debate_tools/토론규칙.md` 하단): 회사 시절의 'ChatGPT 사용량 4% 미만·호출 유예·합의 표시 금지' 규칙을 폐기. 한도 대행 유지, 합의는 명시 수용 시 기록, 합의된 코드 변경은 모의·그림자에만 즉시 반영, 실거래 영향 변경은 사용자 승인 필요. 이후 합의가 기록되기 시작했다(안건 9~14, 17).
10. 이력 관리 체계 구축(이 문서): `HANDOFF.md`, `CLAUDE.md`, `AGENTS.md`, `tools/ai_session.py`(start/end), `docs/ai-history/` 구조. Codex 세션 기록을 `codex-session/`으로 통합.
11. 21:30 사용자 지시: 매수 한도를 사용자가 고정해 제한하지 않는다. 매수 방법과 한도는 두 AI가 협의한다. `운용목표.md`에 안건으로 추가했다. 위험 기반 한도로 대체하는 방향의 협의를 요청했고 실거래 한도(config.json)와 `live.enabled=false`는 변경하지 않았다.
12. 21:40 사용자 보고: 메타플렉스가 +10%까지 올랐다 +4%대로 내려왔으나 익절하지 않음. V5에 익절·추적 손절 규칙이 없다는 코드 사실을 안건으로 올리고 청산 규칙·재개 조건을 토론하게 했다. 합의되면 모의·그림자에 구현하고 실거래 활성화는 승인 후.
