# 상시 위임 확인과 즉시 반영 범위

2026-11-03 11:50 KST. 사용자 원문: “토론결과 타당하면 즉시반영해 항상 허락한다 권한위임”.

ChatGPT는 실제 Claude 응답을 받아 아래 권한·범위를 수용했다. 이 기록은 재승인 대기 때문에 합의된 작업을 멈추지 않도록 하는 변경이다.

## 공동 수용

동의. 상시위임은 사용자 재승인 단계만 생략하는 권한이며 가설 검증을 대체하지 않는다. 양 AI 규칙·권한대장에 '검증된 상호합의는 재질문 없이 코드/실행사본에 반영' 조항을 추가하되 상대검토·테스트·승인해시·미확정주문검사·정상종료·백업/롤백·단일실행권은 유지한다. 기계 권한검사 우회, 키/출금 권한 확대, 원본 공개 범위 확대는 위임 대상이 아니다. 실거래 전략 변경은 합의만으로 부족하고 실측 근거가 있어야 한다.

검증된 합의는 재질문 없이 반영하고 변경 내용·검사·실행 결과를 보고한다. 비밀정보 제외, 도구 자체 권한 검사, 단일 실행권, 상대 검증과 안전한 배포 조건은 유지한다.

## 이번에 실제 반영한 것

- AGENTS.md·CLAUDE.md·권한 대장에 사용자 상시 승인을 추가했다. 기존 이력은 지우지 않았다.
- [기계 판독 비교 명세](../../tools/experiments/cadence_compare.json)를 등록했다. A=15분/60분, B=15분/30분, C=5분/30분+18시간 보존, D=5분/30분+6시간으로 분리했다.
- 다음 작성 Claude·검증 ChatGPT를 명시했고, 동일 기간/위험/비용/보유 조건과 측정 지표를 고정했다.
- 비교 명세 상태는 spec_registered_not_running이다. 구현·비교 실행 완료로 표시하지 않았다.

## 실거래 주기를 지금 바꾸지 않은 이유

30분 교체가 낫다는 실측 비교가 아직 없다. 직전 공동권고도 그림자 비교 선행이었다. 거래 빈도가 늘면 수수료와 과적합 위험이 커지므로 지금은 소규모 실거래 시험도 근거가 부족하다. 배포도구(launch_v5.py)도 부재해 롤백 경로가 검증되지 않았다. 이번 응답은 도구 없는 정적 검토이며 아무것도 실행하지 않았다.

이는 새로운 사용자 허락을 기다리는 상태가 아니다. 앞선 타당한 결론 자체가 '실거래 유지·모의 비교 선행'이었으므로 그 결론을 적용한 것이다. 기술적 배포 조건인 실행기 부재도 사용자 재승인 문제와 구분한다. 평가되지 않은 가설을 실거래 검증 완료로 취급하지 않는다. 봇 코드·실행 사본·실제 설정·주문은 이번에 변경하지 않았다.
