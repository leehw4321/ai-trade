# 2026-11-05 순간 명령창 깜빡임 수정

사용자가 화면에 창이 계속 나타났다 사라져 멀미가 날 정도라고 설명했다. 앞선 봇 종료 원인 설명과 구분되는 콘솔 창 표시 문제다.

## 원인과 변경
- 기존 실행권 자동 이동 감시기 tools/presence_agent.py는10초마다 take_over.bot_running()을 부르며 tasklist.exe로 봇 PID를 조회한다. pythonw 백그라운드 프로세스여도 자식 콘솔 프로그램에 CREATE_NO_WINDOW가 없으면 별도 창이 나타날 수 있다.
- take_over.run()의 Git/보조 프로그램 실행에도 숨김 플래그가 없었다. 표준출력 capture_output만으로 창 표시를 막지는 않는다.
- tools/take_over.py 3개 호출(실행 여부 확인/공통 실행/바로가기 PowerShell), tools/presence_agent.py 2개 호출(중복 실행 검사/설치 PowerShell)에 CREATE_NO_WINDOW만 추가했다. 판단 주기·실행권 이동 규칙·주문·손절 로직은 변경하지 않았다.
- 기존 단일 인스턴스·배포 유예 등 결정 검사9개 통과. 새 저영향 옵션 전용 테스트를 추가하지 않았다.
