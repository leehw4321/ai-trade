## 3. 회피 전략 명세
### A. 우선 비교안: 단기 급등 시 신규 매수 유예
- 기존 상대강도·순위·유동성·보호·재진입 검사를 모두 통과한 후보에만 추가한다.
- 판단 완료 시각T의 종가 C(T)와60분 전 완료 종가 C(T−60m)로 r60=C(T)/C(T−60m)−1을 계산한다.15분 간격의 연속 완료 봉5개가 필요하고, T 이후 봉이나 진행 중 봉은 읽지 않는다.
- **r60≥2.5%이면 이번 정시 슬롯 신규 매수를 보류**한다.2.5%는 제공된9건에서 나온 탐색 후보이며 최적값·검증값이 아니다. 이 숫자를 자료에 반복 맞추지 않는다.
- 다음 정시 슬롯에서 새 완료봉으로 모든 기존 조건과 r60을 다시 계산한다. 과열 해소·순위 적격·유동성 등이 충족될 때만 후보로 복귀한다. 시간이 지났다고 자동 매수하지 않는다. 사용자 보호 종목은 계속 제외한다.
- 실제 적용 설계에는 주문 직전 호가도 동일60분 기준가 대비 상한 미만인지 재검사하고, 신호·기준가·봉시각을 정책 해시로 묶는다. 기존18시간15% 검사도 유지한다. 과거 실행 호가가 없으면 검증 자료는 “확인 불가”로 분리하며 과거 종가로 대신 채우지 않는다.
