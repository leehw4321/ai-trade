# 장세 필터 해제 연구 프로젝트 (2026-11-08 시작)

사용자 지시(11-08): "끄고 거래를 늘려 근거를 찾자. 프로젝트로 리서치해서 보고해줘."

## 1. 질문
상대 강도 순위로 오르는 종목을 사는 이 봇에서, **24시간 시장 균등지수가 음수일 때 연 거래가 양수일 때 연 거래보다 나쁜가?** 나쁘다면 얼마나 나쁜가? 나쁘지 않다면 장세 필터는 거래만 막는 장치이다.

## 2. 배경(왜 의심하는가)
- 장세 필터는 11-03 일봉(199일, 설정 675개 중 앞 100일에서 고르고 뒤 99일 확인)과 15분봉 45개 겹치는 창(H1, 36/45)의 백테스트 **가설**로 들어갔다. ChatGPT·Claude 모두 "겹치는 창·생존 편향이라 실거래 검증이 아니다, 독립 그림자 비교 필요"라고 조건을 달았다(decision-log D-32·D-38·D-39, 2026-11-03-company-claude-review.md).
- 11-04 임시(72시간 만료)로 실거래 적용 → 11-05 11:30 사용자 "유지"(차단 0회라 판단 불가) → 11-07 15:29 목요일 낮 규칙 복귀에서 24시간으로 재적용.
- 11-06 180일 15분봉 5,441건(2026-11-06-regime-window-results.md): 막힌 진입 −0.240% vs 통과 −0.115%, 차이 −0.126%p [−0.359, +0.126] → 0을 포함. 12·6·3시간은 정보 없음. 핵심은 필터가 아니라 진입 규칙의 음의 기대값(비용 전 −0.16%).
- 11-08 봇 실거래 85건(공개 시세로 진입 시점 지수 재계산): 음수장 승률 31% vs 양수장 40%지만 평균 손익은 음수장 −0.28% vs 양수장 −0.50%, 합계 −9,369원 vs −17,293원. 표본이 작아 유의하지 않음.
- 확실한 이점은 "거래 수가 줄어 비용을 아낀다"뿐이다. 음수장에서 오르는 종목이 더 위험하다는 직접 근거는 없다.

## 3. 조치와 설계
- 조치: `strategy.regime_filter` true → false(패치 `tools/patches/regime_filter_off.json`, 11-08 00:5x 배포). 손실 중단선(14,682원)·1회 매수액·4시간 재매수 금지·눌림 조건 0 등 나머지 설정은 그대로.
- 측정: 봇이 1시간마다 `v5/regime_review.py`로 판정하고 `data/regime_review.json`에 진행 상황을 쓴다. 기록 소스는 봇 자신의 시간별 지수(`data/regime_watch.jsonl`)와 거래소 주문 기록(`data/pnl/orders.json`). 진입 시각의 직전 정시 지수가 ≤ 0이면 음수군, > 0이면 양수군. 6시간보다 오래된 지수 기록은 제외.
- 기준(**결과를 보기 전에 고정**, REVIEW_VERSION v1 동안 바꾸지 않음): 양쪽 30건 이상 + 3일 경과에 판정(14일이 지나면 모자라도 참고 판정). 차이 = 음수군 평균 − 양수군 평균(%p, 비용 포함), Welch t.
  - restore(복원 검토): 차이 ≤ −0.3%p 이고 t ≤ −2
  - keep_off(끈 채 유지): 차이 ≥ −0.1%p
  - extend(더 모으기): 그 밖
- 알림: 판정이 나오면 화면 배너와 알림창으로 결과와 할 일을 알린다. restore면 노란 큰 배너. 설정 변경은 사용자 승인 뒤에만.

## 4. 한계(미리 적는다)
- 한 국면(현재 약세 흐름)에서 모은 표본이다. 상승장에서의 결과는 별도 구간이 필요하다.
- 순위·청산 규칙이 다른 두 군이 섞이지 않게 같은 규칙 기간만 쓴다(SINCE 이후). 그래서 모이는 데 며칠 걸린다.
- 필터를 꺼서 거래가 늘면 비용도 늘어 계좌 손실이 커질 수 있다. 손실 중단선(14,682원)이 상한 역할을 한다. 끄는 것 자체가 위험을 키우는 결정이므로 중단선에 닿으면 사용자에게 먼저 알린다.
- 평균 차이만 본다. 큰 손실 한두 건이 결과를 좌우할 수 있어 거래별 내역을 함께 본다.

## 5. 보고 시점
- 자동: 위 기준이 차면 봇이 알린다.
- 중간 점검: 새 대화에서 시작할 때 Claude가 먼저 현재 건수(`data/regime_review.json`)와 손실 중단선 근접 여부를 알린다. 사용자가 "장세 필터 연구 결과 보고"라고 하면 거래별 내역과 함께 보고한다.
- 함께 진행 중인 재매수 점검(눌림 조건 0): `v5/rebuy_review.py`, 이익 청산 뒤 4~24시간 재매수 15건 기준.
