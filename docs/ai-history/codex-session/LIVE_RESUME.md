# 실거래 재개에 필요한 장부 이전

2026-11-02 21:02 KST 읽기전용 확인 결과, 원격 실행 기록에는 이전 실거래 장부의 체크포인트가 있지만 현재 PC에는 `v5-app/v5/data/live/live.json`이 없다. `live.enabled`는 false이며 이번 확인에서 주문은 제출하지 않았다. 체결 대기·예약 대기 주문은 각각0건이었다.

사용자는 실거래 재개를 명시적으로 지시했다. 재개 의사를 다시 확인할 필요는 없고, 필요한 것은 기존 상태 자료다. 계좌 잔고 조회만으로 과거 봇 소유분·손절가·처리한 주문안을 복원했다고 간주하지 않는다.

## 회사 PC에서 가져올 자료

1. 기존 V5 주문 실행 봇과 그림자 제안기를 정상 종료한다.
2. 회사 PC의 V5 `data/` 전체를 비공개 방식으로 이 프로젝트의 `private_handoff/v5-data/`에 복사한다. 특히 `live/live.json`이 반드시 필요하며 주문 기록도 함께 보존한다.
3. 실행 중인 집 PC의 `v5-app/v5/data/`에는 직접 덮어쓰지 않는다. 먼저 별도 반입 폴더에서 원격 체크포인트와 장부 일치를 확인한다. 이 폴더는 Git에서 제외했다.

## 자료 확보 후 처리

원격 최신 체크포인트와 반입 장부 해시를 비교하고, 봇 보유 수량·누적 매수·실현손익·중단 상태·처리한 주문안과 거래소 잔고·미체결을 대사한다. 진행 중인 모의·조회·토론 이력은 보존한다. 이전 주문안이나 현재 모의 매수를 실주문으로 소급 실행하지 않는다. 실행권 및 장부 조건이 충족된 뒤 승인된 기존 한도 내에서 실거래 설정과 실행 경로를 전환한다. 검증 차단을 제거하거나 장부 해시를 임의로 맞추지 않는다.

현재까지는 실거래 전환이나 주문이 이뤄지지 않았다. [검사 결과](docs/ai-history/live-resume-check-2026-11-02.json)를 참고한다.
