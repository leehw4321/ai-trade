# AI 토론장 규칙

참가자: **Claude** (Claude Code 확장) · **ChatGPT** (ChatGPT/Codex 확장) · **사용자** (최종 결정권자)

이 폴더의 `토론.md` 한 파일에서 두 AI가 번갈아 발언하며 합의를 만든다. 사용자는 각 AI에게 "토론장 네 차례야"라고만 말한다.

## 차례가 오면 할 일

1. `토론규칙.md`(이 파일)와 `토론.md` 전체를 읽는다.
2. `토론.md` 맨 위 **현재 차례**가 자기 이름이 아니면 아무것도 쓰지 않고 "지금은 상대 차례입니다"라고만 답한다.
3. 자기 차례면 `토론.md` 맨 아래에 발언을 **추가**한다. 기존 발언은 고치거나 지우지 않는다.
4. 맨 위 **합의 현황** 표를 갱신한다. 상대가 쓴 항목도 상태를 바꿀 수 있지만, 바꾼 이유를 발언에 적는다.
5. **현재 차례**를 상대 이름으로 바꾸고 **회차**를 1 올린다.
6. 사용자에게 채팅으로 3줄 이내 요약을 남긴다.

## 발언 형식

```
---
### [회차 N] 이름 · YYYY-MM-DD HH:MM

**상대 의견에 대한 답**
- 동의: ...
- 반대: ... (이유와 근거)

**새 제안 또는 수정안**
...

**사용자 결정이 필요한 것** (없으면 "없음")
...
```

## 토론 원칙

- 근거는 PC의 실제 파일 경로, 측정 수치, 공개 자료 링크로 댄다. 근거 없는 주장은 "가설"이라고 표시한다.
- 상대가 맞으면 맞다고 쓰고 자기 의견을 수정한다. 이기려고 토론하지 않는다.
- 한 발언은 화면 한 장(약 40줄) 이내. 안건과 무관한 이야기는 쓰지 않는다.
- 같은 주장을 두 번 반복하게 되면 "이견 유지"로 표시하고 사용자 결정 항목으로 넘긴다.
- 토론 중에는 프로젝트 코드·설정·장부를 수정하지 않고, 주문·API 호출도 하지 않는다. 쓰는 파일은 `토론.md`뿐이다. 실험이나 코드 작업은 합의 후 사용자가 따로 지시한다.

## 끝나는 조건

- 합의 현황 표의 모든 항목이 **합의** 또는 **사용자 결정**이 되면, 그 차례의 AI가 맨 아래에 **최종 합의안**을 정리하고 현재 차례를 **사용자**로 바꾼다.
- 6회차까지 끝나지 않으면 남은 이견을 정리해 사용자에게 넘긴다.
- 사용자는 언제든 `토론.md`에 `### [사용자]` 발언을 써서 방향을 바꿀 수 있다. 두 AI는 사용자 발언을 최우선으로 따른다.

## 자동 진행 보완 규칙 2026년 11월 2일

사용자의 자동 토론 시작 지시에 따라 이번 회차부터 진행기를 사용한다.
- AI는 전달된 토론 규칙과 기록만 읽고 답변을 반환한다. 직접 파일·프로젝트·계좌에 접근하지 않는다.
- 진행기만 토론.md의 표와 차례를 갱신하고 발언을 추가한다. 이전 발언 원문은 보존한다.
- 최대6회차, 차례당10분, 호출 하나씩 실행한다. 사용자 편집 감지·응답 형식 오류·호출 실패 시 중단한다.
- 중지 버튼 또는 중지.txt로 멈춘다. 실행 중 창을 닫으면 해당 진행기의 호출을 중지한다.
- API키 환경변수는 전달하지 않고 기존 로그인으로 호출한다. 사용량 제한 또는 추가 결제 요구 시 자동 전환하지 않는다.
- 자동진행기록·진행기록.log·진행상태.txt·잠금·합의안은 진행기가 작성하는 운영 파일이다.
- 두 AI의 합의는 평가 계획에 대한 의견 일치이며 수익성 입증이나 실거래 승인으로 취급하지 않는다.
