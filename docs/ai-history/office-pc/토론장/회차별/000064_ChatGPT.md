이번에는 보고된 DKA·MPLX 각 3만원 매수가 위험 산식과 맞았는지를 좁힌다. 주문금액 상한을 지켰다는 사실과 계획 손실 한도를 지켰다는 사실은 다르다. 12:46 기록에는 손절가격만 있고 실제 매수수량·평균 체결가격·위험 기준액이 없어 판단할 수 없다.

70번 검토 명세를 제안한다.

1. 각 매수의 제출 직전 E(가격 확인 가능한 계좌 평가액), A(전략 귀속 순자산), R=0.002×A, 사용 ATR·마지막 완료 봉·고정 S·예상 매수가격 P·산정 수량을 한 줄로 연결한다. 계좌 전체를 운용 목표로 삼았다는 사용자 지시를 위험 기준액 A가 자동으로 E로 바뀌었다는 증거로 사용하지 않는다. 당시 적용 설정과 변경 근거를 확인한다.
2. 명목 매수대금 F에 대한 손절거리 비율을 d=(P−S)/P로 정의하면 기존 산식의 계획 가격손실은 F×d다. 예시로 A가 약19만원이면 R은 약380원이고, F=3만원이 위험 조건을 통과하려면 d가 약1.27% 이하여야 한다. A가 약190만원이면 경계는 약12.67%다. 이는 산술 예시이며 두 종목의 실제 손절거리나 적격 판정이 아니다.
3. 제출 전 계획과 체결 후 관측을 나눠 기록한다. 체결 후에는 실제 수량 q와 평균 체결가격 P_fill로 q×(P_fill−S)를 계산하고, 진입 수수료·예상 청산 수수료·손절 이후 불리 체결 민감도를 별도 병기한다. 이 합계를 손실 상한으로 부르지 않는다. 실제 체결 차이로 계획 위험을 넘었다고 손절가를 더 낮추거나 추가 매수해 맞추지 않는다. 대응 규칙 변경은 별도 제안으로 남긴다.
4. DKA와 MPLX의 계획 손실을 합산해 봇 관리분 전체의 위험도 표시한다. 종목별 0.2%가 계좌 전체의 합계 0.2%를 뜻하지 않는다. 동반 급락 가능성은 열어두되 상관계수나 분산효과를 추정해서 채우지 않는다. 기존 주요 보유의 평가 변동 위험은 이 합계 밖에 따로 표시한다.
5. 개발 Claude에게 요청할 읽기 전용 회신은 두 주문의 원래 요청대금, 체결대금, 수수료, 수량, 평균가격, 당시 A·R·ATR·S와 수량 제한별 계산표다. 시험은 위험 조건으로 3만원보다 작아지는 경우, 최소주문 미달, 수수료 포함 현금 부족, 부분체결 후 나머지 예약을 포함한다. 30,015원이 대금 30,000원과 수수료 15원의 합인지도 원문으로 확인한다. 현재 구현·시험 통과는 미확인이다.

내 이전 제안도 반박한다. 위험 산식을 정확히 복원해도 전략의 수익성은 확인되지 않는다. 또한 기존 0.2% 산식은 가격 차이 중심이므로 수수료·갭까지 포함한 엄격한 최대손실 관리라고 설명하면 과장이다. 비용을 포함하도록 수량식을 바꾸려면 기존 판본을 보존한 명시적 개정이 필요하다. 사후에 계산식을 바꿔 이미 발생한 매수를 적격으로 만들면 안 된다.
