## 먼저 알아둘 것 (기술적 사실)
- 이 문서는 **사용자 위임의 범위를 두 AI에게 알리는 기록**이다. 각 도구 자체의 권한 시스템(예: Claude Code의 `.claude/settings.local.json`, Codex의 자체 설정)은 별개이며 이 문서가 바꾸지 않는다. 도구가 자기 권한 검사에서 막으면 사용자가 그 도구의 설정에서 허용해야 한다. (Claude Code는 `코인 트레이딩\.claude\settings.local.json`에 배포 명령 허용 규칙이 있다.)
- 토론 세션의 ChatGPT는 도구가 꺼져 있어 파일·계좌·주문을 직접 다루지 못한다. 그 세션의 '권한'은 **합의를 통해 합의 게이트(`tools/consensus_gate.py`)가 사용자 대신 적용하게 하는 것**으로 행사된다. Codex 개발 세션은 코드를 직접 수정·배포할 수 있다.

## 두 AI 모두에게 계속 적용되는 한계 (사용자가 풀지 않은 것)
1. **실거래 켜기/끄기(`live.enabled`)와 계좌 인수 범위**는 사용자의 명시 지시 없이 바꾸지 않는다.
2. **비밀값**(키, 시크릿, 토큰, 계좌번호, 주문 UUID, `.env`)은 어떤 문서·커밋·로그에도 쓰지 않는다.
3. 같은 계좌를 두 PC가 동시에 실거래하지 않는다. PC 교대는 실행권 양도 절차를 따른다.
4. 이미 본 데이터에 맞춘 임계값을 '검증됨'이라 부르지 않는다. 수익이 보장된다고 말하지 않는다.
5. 단독 판단을 합의로 기록하지 않는다. 상태(실거래 켜짐 여부, 봇 실행, 보유)를 말하기 전에 `python tools/ai_session.py status`를 실행한다.
6. 권한 검사기(도구의 안전장치)가 어떤 동작을 거부하면 우회하지 않고 사용자에게 알린다.
