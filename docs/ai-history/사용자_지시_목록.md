# 사용자 지시 목록 (화면·기능 요청 대장)

사용자가 준 화면·기능 지시를 한 줄씩 적는다. 두 AI(Claude·ChatGPT)와 두 PC 공통. 기록은 추가만 한다.
만든 사람이 "완료"로 바꾸려면 아래 네 칸이 모두 채워져야 한다.
- **원문**: 사용자 말 그대로(요약 금지). 범위를 좁혀 구현했다면 '구현 범위'에 무엇을 뺐는지 적는다.
- **테스트**: 그 지시를 지키는지 확인하는 테스트 이름. 테스트가 깨지면 배포가 막힌다(deploy_v5.py가 테스트 실패 시 배포 거부).
- **화면 확인**: 실제 화면(data/status.html)에서 지시한 내용이 보이는 것을 확인한 시각과 PC. 조건부 표시라 지금 화면에 안 나오면 "조건 때문에 안 보임"이라고 적고 사용자에게 말한다.
- **두 PC 반영**: 집 PC·회사 PC 각각 배포 시각.
