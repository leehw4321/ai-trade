# 집 PC 할 일 (회사 PC에서 남김, 2026-11-12)

사용자가 "할 일 해줘"라고 하면 Claude는 이 파일의 미완료 항목을 순서대로 진행한다. 끝난 항목은 [x]로 바꾸고 시각·결과를 적은 뒤 커밋·푸시한다.

## 1. [ ] 재매수 눌림 조건 0.5ATR 배포 (사용자 지시 11-12 ".5적용")
- 근거: [11-12 기록](2026-11-12.md) "이익 청산 후 재매수 눌림 조건 0 → 0.5ATR". 합의 설정에는 이미 반영됨(커밋 0645db7).
- 순서:
  1. `git pull`. 집 PC에 올리지 않은 변경이 있으면 멈추고 사용자에게 알린다.
  2. `python tools/deploy_v5.py --apply --patch tools/patches/reentry_dip_05_20261112.json`
  3. 장부(data/live/live.json)는 직접 고치지 않는다(11-11 09:46 실행권 공백 재발 방지).
  4. 확인: 실행권이 집 PC에 있음, 실행본 config `reentry_dip_atr`=0.5·`stop_max_pct`=0.035, 실행본 코드 = 정본, stderr 새 오류 없음.
  5. 결과를 11-12(또는 오늘) 기록에 남기고 이 항목을 [x]로 바꾼 뒤 커밋·푸시.
- 참고: 봇 화면의 "재매수 사후 점검" 공지는 이 결정으로 처리된 것이므로 사용자에게 '확인했습니다'를 눌러도 된다고 알린다.
