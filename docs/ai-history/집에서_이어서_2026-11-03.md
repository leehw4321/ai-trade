# ChatGPT·Claude 공통 재개 문서 — 집에서 이 파일부터 읽기

**두 AI 모두 읽어야 할 문서는 이 파일 하나로 통일합니다.**
경로: `docs/ai-history/집에서_이어서_2026-11-03.md`

이 문서는 세션/PC가 바뀌어도 같은 목적·권한·보호 목록·완료 사항·미해결 과제에서 출발하기 위한 공통 시작점입니다. 아래 본문과 최신 정정까지 끝까지 읽으면 맥락을 파악할 수 있습니다. 연결된 상세 문서는 해당 코드를 검토할 때만 추가로 읽습니다. 과거 기록과 충돌하면 날짜가 최신인 명시적 사용자 지시를 적용합니다.

## 새로 호출된 AI가 바로 수행할 일

1. 프로젝트 저장소에서 최신 코드를 받는다. `python tools/ai_session.py start`는 Git 갱신 후 이 공통 문서를 먼저 표시한다. 충돌이나 갱신 실패를 숨기지 않는다.
2. **DOGE 사용자 보호가 최우선이다.** 실제 집 실행 폴더를 먼저 확인하고 `tools/protect_asset.py --app "<실행폴더>" list`로 목록을 확인한다. DOGE가 없으면 사용자의 기존 명령에 따라 `protect DOGE`로 등록한다. 사용자 해제 지시 없이 거래소의 DOGE 주문을 취소·변경하거나 봇으로 매수·매도·손절·익절하지 않는다.
3. `python tools/ai_session.py status`로 **지금 이 PC**의 실행 상태를 읽는다. 회사 PC의 마지막 상태를 집 PC의 현재 상태라고 말하지 않는다. 원격 상태는 따로 확인하기 전까지 미확인이다.
4. 코드/문서 작업은 바로 이어간다. 실거래 시작·PC 전환에는 아래 비공개 장부 이전 및 실행권 확인을 먼저 수행한다. `git pull`만으로 계좌 이전이 끝났다고 간주하지 않는다.
5. 읽고 확인한 직후 사용자에게 **현재 상태 / DOGE 보호 확인 / 지금 이어갈 작업**을 짧게 보고하고 작업한다. 지금까지의 논의를 사용자에게 다시 설명해 달라고 요구하지 않는다.

## 두 AI의 협업 방식 — 중복 수정 방지

- 양쪽의 제안·검토·결정권은 동등하다. 주진행자는 결정권의 우열이 아니다.
- 2026-11-03 15:40 KST까지는 사용자가 승인한 ChatGPT 단독 전담이다. 집에 돌아온 시간이 그 이후라면 그 임시 권한을 영구 위임으로 해석하지 않는다.
- **집 재개 후 첫 새 변경:** Claude가 작성, ChatGPT가 검증을 맡는 것을 기본으로 한다. 현재 진행 중인 변경이 확인되면 그 담당을 먼저 존중한다. 이후 변경 단위로 역할을 교대한다.
- 착수할 때 안건·수정 파일·작성자·검증자·완료/미적용 상태를 이 문서 끝의 작업 기록에 남긴다. 상대가 같은 파일을 수정 중이면 덮어쓰지 않는다. 이 문서 기록은 조율 규칙이며 실제 분산 잠금 기능이 구현됐다는 뜻은 아니다.
- 실제 상대 응답을 받은 것만 합의로 기록한다. Claude CLI를 도구 없이 호출할 경우 상대는 파일을 읽을 수 없으므로 **관련 코드/차이/검사 결과/검토 대상 해시를 요청에 포함**한다. 경로만 보내 놓고 검토됐다고 간주하지 않는다.
- 상대 한도/접속 실패는 그대로 보고한다. 명시적으로 허용된 대행 범위에서 진행하고, 자기 판단을 상대 승인으로 꾸미지 않는다. API 유료 과금으로 임의 전환하지 않는다.
