# 봇 재현 기록 읽는 순서
이 기록은 2026년 11월 6일 회사 PC 실행 폴더의 디스크 소스를 특정 시점에 고정한 것이다. 실행 프로세스의 메모리 코드까지 대조한 인증은 아니다.
1. bot-specification.html — 사람이 읽는 본문과 주의사항
2. bot-specification.md — 같은 본문의 AI용 원문
3. technical-appendix.md — 설정 기본값과 덮어쓰기 결과, 모듈·함수·테스트 색인
4. effective-settings.json / settings.snapshot.json — 기계가 읽는 합성 설정 / 캡처 설정
5. source-manifest.json / function-contracts.json — 원본 코드 해시 / 함수별 참조
6. 재현 패키지 안 runtime-source.zip — 이 시점의 코드와 테스트 원본. 비밀키·실제 거래 장부·계좌 인수 식별자는 포함하지 않음.

실제 계좌를 옮기는 자료가 아니다. .env와 개인 장부, 보호선 고점, 미확정 주문, 실행권, 손익 기준은 Git이나 이 문서만으로 복원되지 않는다. 별도 비공개 인수 절차가 필요하다.
현재 설정에는 실거래 활성 값이 기록되어 있다. 학습/재구현 환경에서는 live.enabled=false, auto_proposal=false로 시작하고 네트워크 주문을 차단해야 한다. 이 문서는 거래 개시나 설정 변경 지시가 아니다.
제안 중인 전략과 실제 구현은 본문에서 구분한다. 정체 탈출 exit_watch는 기록 전용이며 매수 1호가 지정가 진입은 연구 제안이다. 자동 AI 반복 호출은 폐기 상태로 복원 금지.
같은 결과를 재현하려면 코드·설정뿐 아니라 동일한 입력 데이터·시각·초기 상태가 필요하다. 수익성은 별도 검증 대상이다.

Git에서 받는 경우 source/ 아래 .py.txt 원문과 source-manifest.json으로도 같은 코드를 복원할 수 있다. .txt 파일은 실행되지 않도록 저장한 원본이며, 복원 전에 해시를 확인한다. 개인 장부는 포함되지 않는다.
