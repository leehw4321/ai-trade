# 자동거래 V5 및 AI 토론 작업 인계

기준일: 2026-11-02, 한국 시간. 이 문서는 집에서 개발을 이어가기 위한 요약이며 수익성 검증 보고서가 아닙니다.

## 사용자 목표와 개발 경과

사용자는 기존 업비트 계좌의 원화와 보유자산을 출발점으로, 기존 종목 유지·축소·교체·신규 투자를 판단하는 수익 구조를 원합니다. 거래 빈도보다 비용 후 수익 우위가 먼저 검증되어야 한다는 방향으로 논의했습니다. 기존 단기 전략 손실과 과도한 진입 제한에 대한 검토에서 시작해 공통 평가 틀, 장기 추세추종, 장중 순환매, 4시간봉 상대강도 순환 후보를 비교하자는 방향을 논의했습니다.

그 뒤 사용자가 1시간·4시간 판단은 길다고 요청하여 현재 V5 전략 판단은 15분봉, 관측 72봉(18시간)으로 변경됐습니다. 주기 변경은 수익성 개선의 증거가 아닙니다. 상승률을 상대강도로 부르는 현재 코드의 실제 산식을 확인하고, BTC 대비 지표가 구현됐다고 추정하지 마세요.

## 실제 구현과 미완료 사항

1. V4는 저장소 루트, V5 최신 코드는 `v5/`에 있습니다. 원래 개발 PC에서는 서로 다른 Git 저장소였으며 이번에 V5 현재 파일을 이 저장소로 묶었습니다.
2. V5에는 모의 장부 두 개, 12개 그림자 변형, 실제 주문 실행기가 있습니다. 실제 운용 PC에서는 실주문 체결 기록도 발생했습니다. 구형 README의 '실제 주문 없음' 문구는 현재 사실과 달라 교체했습니다.
3. 기존 계좌 보유는 계좌 조회 표에 나타납니다. 모의 ALL 장부나 봇이 새로 산 종목 장부와 동일하지 않습니다. 계좌 전체 인수 장부·기존 종목 관리 정책은 별도로 점검해야 합니다.
4. 계좌 API는 정상인데 표시가 거래 전 상태에 머무는 문제를 확인했습니다. 처음에는 30초 갱신을 추가했고, 현재는 전략 계산과 독립된 5초 간격 조회 프로세스로 분리했습니다. 조회 실패·지연·미평가 자산 수량을 표시합니다. 실시간 푸시 방식은 아닙니다.
5. 점수=(최근 상승률/변동성)×유동성 보정, 거래대금 100억 기준, 예산 50% 상한, 전체 기본 6종목은 사용자에게 전달된 Claude 제안입니다. 공동 합의와 구현 완료를 확인하지 않았습니다. 현재 제안 배분 로직과 실행 한도 파서가 지원하는 항목을 먼저 확인해야 합니다.
6. 복수 전략을 같은 데이터·비용·위험 조건에서 비교하고, 이미 반복 확인한 기간을 독립 최종 시험이라고 부르지 않는 원칙을 유지합니다. 미평가·상장폐지·자료 누락·생존 편향을 공개하고 실제 없는 호가 이력을 재현했다고 주장하지 않습니다.

## 두 AI 역할과 토론

Claude 주진행, ChatGPT 검토가 기본입니다. 한쪽 사용량이 소진되면 사용 가능한 AI가 대행하도록 사용자가 위임했습니다. 단독 검토를 두 AI 공동 합의라고 쓰면 안 됩니다. 둘 다 불가하면 사용량 재확인까지 기다립니다. 과금 API로 자동 전환하지 않습니다.

자동 토론은 순차 CLI 호출, 파일 잠금, 편집 해시 확인, 1시간 보고서, 회차별 기록 구조입니다. 토론용 CLI는 도구를 끈 추론 세션이므로 스스로 파일을 수정하거나 실계좌를 조회했다고 주장하면 안 됩니다. 실제 코드 수정·테스트는 별도 개발 세션에서 수행합니다.

`debate_tools/`에는 진행기와 현황·재개 도구, 규칙, 재개용 빈 토론을 포함했습니다. 기존 계좌 수치·주문안·응답 로그·사용량 대기 시각은 포함하지 않았습니다. 새 토론은 1번부터 시작하는 템플릿이며 과거 발언 복원본이 아닙니다. 현재 진행기의 상호 위임 변경은 기존 ChatGPT 유예와 Claude 대기 구조를 활용한 것으로, 양쪽 한도·회복·재시작 전체 흐름은 추가 검토가 필요합니다.

## 집에서 토론 재개

두 AI의 CLI가 설치·로그인되어 있어야 합니다. 진행기는 VS Code 확장의 실행 파일을 탐색합니다. 프로그램 버전에 따라 CLI 옵션 호환 확인이 필요합니다.

```powershell
# 저장소 루트에서, 새 PowerShell 창마다 필요한 환경변수를 설정합니다.
$env:AI_DEBATE_DIR = (Resolve-Path .\debate_tools).Path
$env:V5_ROOT = (Resolve-Path .\v5).Path
cd debate_tools
python 토론진행기.py --continuous-run
```

`중지.txt` 파일로 토론을 중지합니다. 실행 중 `토론.md`를 외부에서 바꾸면 충돌 방지 기능이 멈출 수 있습니다. 시작 시 기존 운용 PC의 토론 진행기도 정리해 중복 사용량 소모를 피하세요. 토론 중지와 거래 봇 중지는 서로 다릅니다.
