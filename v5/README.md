# V5 — 집에서 작업 이어가기

2026-11-02 현재 개발 코드입니다. Python 3.10 이상과 표준 라이브러리를 사용합니다. `account_sync.py`는 Windows 전용 파일 잠금을 사용합니다.

## 처음 시작

```powershell
git clone https://github.com/leehw4321/ai-trade.git
cd ai-trade\v5
Copy-Item .env.example .env
# .env에 본인 업비트 키를 직접 입력합니다. 파일을 Git에 추가하지 않습니다.
python -m unittest -q
python account_sync.py
```

`data/account_live.html`을 브라우저에서 열면 실제 잔고·잠금 수량·평가액을 약 5초 간격으로 확인합니다. 조회 실패 시 15초 후 재시도하고 마지막 성공 자료를 표시합니다. PC·통신 상태에 따라 지연될 수 있습니다. `account_sync_stop.txt`를 만들거나 콘솔에서 Ctrl+C를 누르면 조회기가 종료됩니다.

모의 전략과 전체 화면은 `python bot.py`로 시작합니다. `data/status.html`을 여세요. 종료는 `stop.txt` 파일을 만들면 됩니다. 봇이 시작하는 조회기는 별도 프로세스이므로 조회까지 중지하려면 `account_sync_stop.txt`도 만드세요. 다시 시작할 때는 이 조회 중지 파일을 지워야 합니다.

## 실거래와 상태 이전

### 다른 PC에서 실행할 때

최신 `bot.py`는 GitHub 저장소의 **별도 `bot-session` 브랜치**로 실행권을 확인합니다. 다른 PC가 실행 중이면 **“다른 기계에서 작동 중입니다. 기존 연결을 끊고 이 연결을 유지할까요?”** 확인 창이 나옵니다. 아니요를 누르면 기존 봇을 유지합니다. 예를 누르면 기존 봇에 양도를 요청하고, 기존 봇이 주문 처리를 마치고 종료한 뒤 새 PC가 실행권을 얻습니다.

양도는 최대 약 4분까지 기다립니다. GitHub 연결이나 인증이 실패하면 새 주문을 차단합니다. 기존 PC의 정상 종료를 확인할 수 없는 상태에서는 실거래를 강제로 이어받지 않습니다. 기존 PC와 집 PC 모두 이 기능이 포함된 최신 버전을 사용해야 합니다. 조회 전용 `account_sync.py`는 두 PC에서 동시에 사용할 수 있습니다.

두 PC에서 Git 설치와 저장소 쓰기 권한 인증이 필요합니다. 처음에는 PowerShell에서 `git push`가 가능한지 확인하세요. `bot-session`에는 임의 세션 ID·유효 시각·장부 해시만 저장하고 API 키·잔고·주문 이력은 저장하지 않습니다. 기본 저장소를 바꾸려면 `config.json`의 `session.remote`를 지정합니다. 같은 계좌를 쓰는 모든 PC는 같은 저장소로 설정해야 합니다.

**실행권 양도는 장부 복사가 아닙니다.** 실거래를 켠 새 PC의 장부가 종료한 기존 PC의 장부와 다르면 실행을 막고 `data/` 비공개 이전을 안내합니다. 코드가 업비트 앱·웹이나 이 기능이 없는 다른 거래 프로그램의 주문까지 막는 것은 아닙니다.

이 코드에는 **실제 주문 기능이 있습니다.** GitHub용 `config.json`은 `live.enabled=false`, `live.auto_proposal=false`로 저장했습니다. 현재 운용 PC의 설정은 바꾸지 않았습니다.

운용 PC와 집 PC를 동시에 실거래로 실행하지 마세요. 기존 실거래를 집으로 넘길 때는 먼저 원래 PC의 주문 실행 봇과 그림자 제안기를 정상 종료하고, `data/` 전체를 별도의 비공개 방식으로 옮겨야 합니다. 특히 `data/live/live.json`에는 봇 보유분·손절가·누적 매수·처리한 주문안 상태가 있습니다. 이 상태를 생략하면 중복 주문 방지와 기존 봇 보유분 관리가 이어지지 않습니다. API 조회만으로 이 기록을 자동 복원하지 않습니다.

`.env`와 `data/`는 GitHub에 없습니다. API 키는 집 PC에서 별도 설정하고 업비트의 허용 IP 설정도 확인하세요. 과거 토론의 실행 주문안을 새 토론 파일에 복사해 재실행하지 마세요.

## 현재 구조

- `strategy.py`: 15분봉 상대강도, 최근 72봉(18시간), 거래대금 상위 30 대상. 수익성 미검증.
- `bot.py`, `paper.py`: 모의 장부 P10·ALL, 전체 현황. ALL은 가상 현금 전략 실험이며 기존 계좌 전체를 인수한 장부가 아닙니다.
- `live.py`: 설정 한도 안의 실주문 및 손절. 자동 제안 실행도 있으므로 모의 전용 프로그램으로 오해하지 마세요.
- `shadow.py`: 전략 변형 비교와 주문 제안 작성. 실거래 설정이 켜지면 제안이 실행 경로에 연결됩니다.
- `account_sync.py`: 매매 판단과 독립된 계좌·시세 조회, JSON/HTML 원자 저장, 중복 실행 잠금.
- `upbit.py`: API 연결. 키는 환경변수 또는 로컬 `.env`에서 읽습니다.

코인별 상승률/변동성·유동성 점수 배분, 전체 6종목, 예산 50% 상한은 제안 단계입니다. 구현·공동 합의 완료로 간주하지 마세요.

토론 파일 위치는 `AI_DEBATE_DIR` 환경변수로 지정할 수 있습니다. 기본은 사용자 홈의 `Desktop/AI토론장`입니다. OneDrive 바탕화면 등을 쓰면 명시적으로 설정하세요. 전체 경과는 [작업 인계](../docs/작업인계_20261102.md)를 읽으세요.
